## Scope and source selection

Feature 8A3 reuses Feature 7 economics, thresholds, gates, buckets, setup types,
ranking, and coverage rules without modification. SEC remains the default.
Explicitly select FMP to screen the latest persisted S&P 500 membership snapshot,
including distinct share classes and members without usable annual histories.
Missing evidence retains `FAILED`, `PARTIAL`, and `NOT_EVALUABLE` outcomes.

FMP annual canonical facts come from the provider-isolated histories persisted
by [Feature 8A2](feature_08a2_fmp_evidence.md). They are not rebuilt from raw
statement payloads during browsing and never filled from SEC. SEC remains
authoritative for filed accounting facts; FMP supplies normalized evidence,
not investment truth. OwnerLens calculates the economics and screening.

## Offline workflow

After completing evidence ingestion into your configured database, generate
the current screen without network access:

```powershell
uv run owner-lens screen --provider fmp
uv run owner-lens screen --provider fmp ADBE GOOG GOOGL --detail
uv run owner-lens evidence-status
```

No separate persisted screen table or screen-refresh job is necessary. The CLI
computes from persisted annual canonical inputs. The existing five-year
analysis window remains the default; `--max-years` explicitly changes it.
The workbench independently caches the same deterministic results.

Launch with FMP selected:

```powershell
uv run owner-lens workbench --provider fmp
```

Use `--db data\ownerlens.db` to select a database, if needed. The raw snapshot
directory remains configured by `OWNER_LENS_RAW_DATA_PATH`. You can switch
between SEC and FMP in the sidebar. Selecting a provider does not fetch data.
After separately refreshing evidence, reopen the workbench or choose
`Reload persisted data`.

## Existing pages

* Overview shows current persisted membership size, provider, observation time,
  coverage counts, bucket counts, and the existing research funnel.
* Screener includes every current FMP member. Existing sorting, filters,
  dimensions, and reasons are unchanged. The optional Improving Economics
  review view selects WATCH and LOW_PRIORITY companies with five usable annual
  observations, positive FCF and FCF/share in all five, rising FCF and FCF/share
  in each of the latest two observations, and latest revenue above the oldest.
  It preserves the original priority, coverage, gate, reasons, and Feature 7
  ranking. The view also displays diluted shares across those observations so
  share-count expansion remains visible. It is not a valuation signal.
* Company retains annual economics and screening. Separate sections show
  quarterly FACT evidence, the latest reliable EOD market close, and Market
  Expectations labeled `EXPECTATION`. None enters annual screening. Prices
  show market date and retrieval provenance without inferred currency.
* Compare supports the existing two-to-five-security comparison, including
  share classes and incomplete companies. Unavailable values remain `N/A`.
* Data Quality shows annual coverage, screening blockers, per-dataset states,
  failures, and raw snapshot provenance. The annual input hash and exact
  fact-linked source snapshots are distinguished from latest dataset attempts,
  which may have failed while an earlier usable history remains available.
  Metrics with no facts retain their coverage diagnosis; latest raw dataset
  provenance is still shown.

Annual history observation times, raw retrieval times, estimate target dates,
and content hashes remain visible. Estimates are snapshots of expectations,
not reported facts, assumptions, or forecasts generated by OwnerLens.

## Caching and validation

The company list and evidence fingerprints are read from SQLite each rerun.
Derived results are cached by provider, database, annual history, and evidence
state. Full-universe screening uses per-security caches and a transient shared
SQLite connection on cache misses. Updating one security does not reconstruct
all histories. Data Quality reuses cached annual screening for its universe
grid and loads detailed provenance only for the selected company.

Fixture-only tests cover 503 securities, unchanged Feature 7 output, explicit
provider selection, incomplete histories, distinct share classes, cache reuse,
Compare, Data Quality, separate enrichment, and all five Streamlit pages with
HTTP access prohibited. No live FMP key is needed.

No valuation, scenarios, probabilities, portfolio logic, AI, historical price
charts, Feature 7 gate or bucket changes, or cloud services are introduced.
